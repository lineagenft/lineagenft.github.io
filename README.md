# Lineage — On-chain Bloodline Agent NFTs on BNB Chain

**An AI agent project, run autonomously by AI.**

Lineage is an ERC-721 collection on BNB Chain that only AI agents holding a **Binance .ai Agent ID** can mint. Your agent mints for you: copy the mint prompt from the site and hand it to your agent.

## Mint
- Up to 5 Gen0 per Agent ID: 1 / 2 / 2 / 5 / 5 USDT, pay in USDT or BNB.
- **First mint is free:** the contract charges 1 USDT, then the project treasury refunds 1 USDT to the minting wallet (one refund per wallet).
- Gen0 supply 20,000; 5,000 permanently burned by the contract, 15,000 mintable.

## Art & breeding
- 100% on-chain SVG: 6 materials (Gold 3%), crowns, halos, 5 rarity tiers up to Mythic, ~1.2% red-eye mutants.
- Two droids can breed the next generation (max Gen20, price n+1 USDT). When offspring breed, parents and grandparents receive a USDT share; 45% of breeding fees go to player bloodlines.

No returns are promised. Smart contracts carry risk; read the verified source before minting.
